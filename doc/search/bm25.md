# Okapi BM25

Select `NEVIS_SEARCH=bm25` and set `NEVIS_POSTGRES_DSN`; see the [API setup](../../README.md#api). The implementation lives in [bm25.py](../../src/nevis_search/search/bm25.py). No model, new dependency, schema change, or persisted index is required.

## Mechanism

[Shared routing](../../src/nevis_search/search/query_routing.py) preserves literal client and document lookup. It narrows document candidates when it recognizes a unique owner and tries the residual query literally. BM25 runs only when that literal search has no matches. Owner recognition is not authorization.

Title and body are concatenated as one equally weighted field. Tokenization is case-folded Unicode word runs; punctuation splits and repeated query tokens count once. The scorer uses Okapi BM25 with `k1=1.2`, `b=0.75`, positive Robertson-style IDF `ln(1 + (N − df + 0.5)/(df + 0.5))`, and insertion order for ties. The candidate postings are rebuilt on each ranked query in this small prototype.

## Evaluation

The branch experiment compared the same router with and without the BM25 callback. Both kept **5/5 exact-set**; BM25 raised Reed **top-1 from 1/10 to 3/10** and **hit@5 from 3/10 to 8/10**. Two top-1 gains were variants of the same signed-release task. For `reed permission to share with accountant`, the signed release had body hits for `permission` and `accountant` (contributions 1.947 and 1.468). For `reed latest 401(k) statement`, June and March tied at 3.300 and March won by insertion order. `reed 401k` returned no documents: `401k` and `401(k)` tokenize differently. `utility bill reed` found only the superseded address bill; the current bill did not contain either token.

In the 11-document Reed slice, the experiment measured a median **0.325 ms** to build postings, about **72 KiB** of transient Python allocation, and no persistent artifact. These index-only results exclude DB access and are not a production benchmark.

Run the acceptance tests and the focused scorer/owner-routing tests, then the official quality eval:

```sh
uv run --locked pytest --no-cov
uv run --locked pytest -s --no-cov evals/ -k bm25
```

A nonzero exit from the second command is expected when any Reed query misses. The [fixture guide](../../evals/README.md) defines the synthetic as-of date; BM25 does not parse dates or signed status. Relevance is not evidence verification.
